## gamba-limit-bot

🎰 telegram bot for slot machine spins, stats & leaderboard

- detects 🎰 dice messages and tracks your spins
- max 3 spins per hour (cheater gets told off)
- `/top` — leaderboard sorted by wins & win rate
- `/stats` — drop rate for each symbol
- `/notify` — DM when your cooldown resets

### env vars

`TELEGRAM_API_TOKEN` — telegram bot token
